# Istruzioni per contribuire

Grazie per l'interesse nel progetto di traduzione italiana di Undertale: Uncanny.

## Traduzione

Le stringhe vengono gestite tramite Crowdin. Prima di proporre una modifica:

- consulta il glossario;
- conserva placeholder e codici di formattazione;
- considera il contesto della stringa;
- evita traduzioni letterali innaturali;
- segnala eventuali dubbi al team.

## Revisione

Ogni modifica deve essere controllata per terminologia, grammatica, tono e compatibilità con il gioco.

## Repository

I file esportati da Crowdin, come `it.json`, non devono essere modificati manualmente salvo emergenze concordate con il team.
