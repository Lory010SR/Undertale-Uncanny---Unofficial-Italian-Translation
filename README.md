Undertale: Uncanny - Italian Translation Project 🇮🇹
Welcome to the official repository for the Italian localization of Undertale: Uncanny, a fan game developed by Vinesoft. 
This project is managed by our translation team, and our goal is to fully translate the game's dialogues, interface, and text strings into Italian, making this amazing horror experience accessible to the Italian community.
📌 Project StatusCurrent Target: Translating the Demo version.
Format: Working with internal .json / .csv localization files.Guidelines: Keeping code syntax, formatting tags (\n, colors, variables), and the original Undertale tone completely intact.
🤝 How We Work 
To avoid conflicts, file corruption, or game crashes, we manage string localizations through structured translation tools (Crowdin / Google Sheets). If you are part of the team, please check the assigned rows or files before making any modifications.
